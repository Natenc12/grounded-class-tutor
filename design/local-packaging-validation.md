# Personal Mac preview validation

Observed October 2, 2026 on an Apple Silicon Mac running macOS 26.5.2. This is
the self-contained personal preview under `desktop/PACKAGING.md`, not a notarized
public release or a clean-machine certification.

## Artifact and runtime

`Grounded-Class-Tutor-0.1.0-mac-arm64.zip` contains the app with Electron 42,
CPython 3.13.14, the GCT core and locked runtime dependencies. The observed ZIP
is 159,829,477 bytes with SHA-256
`7159699ef18bcfdaaf54cd5d87a8f4d6be88fca6f00b11c580b666d33ec5d0d2`.
These identify this local artifact; a rebuild may produce different archive bytes.

The packaging smoke copied the app outside the checkout into a path containing
spaces and a non-ASCII character. Its shipped bridge and isolated Python passed:

- PDF and PowerPoint creation/import, extraction and saved reopening after the
  original synthetic files were removed;
- SQLite FTS5 and separate-process library persistence;
- a mocked generation handshake, exact saved citation lookup and deletion;
- a consistent backup reopened as a separate library;
- the bundled sample and 51 native-library dependency checks.

Invalid developer Python paths and inherited Python configuration could not select
a different interpreter. All Python imports resolved inside the relocated bundle.
The smoke found no generated bytecode in the app. It does not instantiate a live
SDK account or exercise native Electron UI.

The final desktop suite passed 138 tests. An independent architecture reviewer
ran 41 packaging/runtime/lifecycle tests and verified every main-process launch
path forwards the bundled-runtime configuration. Existing child cleanup,
account cancellation and encrypted shutdown behavior remain intact.

## Independent package audit

A separate governance reviewer inspected 1,850 bundle entries and 204 ASAR entries.
All eight application inputs and all 18 GCT Python files matched reviewed source.
No course documents, account records, library database, environment files or
checkout contents entered the payload. The exact Electron/Chromium notices,
19 upstream Python license texts and metadata, six third-party wheel notices,
Node dependency licenses and SDK modification notice were verified. Deep, strict
ad-hoc signature verification and six packaging tests passed independently.

## Native launch boundary

The lead launched a relocated app with only system tools on PATH and invalid
developer-Python overrides. Its main and renderer processes started, then macOS
opened a protected Keychain prompt while accessing the existing connection.
The computer-control tool cannot access that protected system dialog; the user
was asked to complete it. Account continuity and the complete native workflow are
not claimed until that prompt and a connected app check finish.

The app name, account encryption identifier and existing application-data path
remain unchanged. Neither packaging nor the synthetic smoke copies or resets
that data. There is no valid Developer ID identity on the build Mac, no notarization,
and no automatic updater. A changed ad-hoc signature may request Keychain access
again. Fresh-Mac installation, signed updates, upgrade/rollback recovery and the
deferred visual redesign remain separate acceptance work in issue #167.
